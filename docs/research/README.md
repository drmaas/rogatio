# Frozen decision history — research

This directory is **read-only decision history**. Files here were moved from `docs/decisions/<feature>/research.md` on release or supersession and are no longer edited in place.

To understand what the system does, read the code. To understand what the codebase looked like when a feature was researched, read the file in this directory. If a file's content disagrees with the code, the code wins — the disagreement is recorded in the `> Superseded by:` footer on the next review.
