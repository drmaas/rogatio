# Frozen decision history — specs

This directory is **read-only decision history**. Files here were moved from `docs/decisions/<feature>/spec.md` on release or supersession and are no longer edited in place.

To understand what the system does, read the code. To understand why a feature is the way it is, read the file in this directory. If a file's content disagrees with the code, the code wins — the disagreement is recorded in the `> Superseded by:` footer on the next review.
