# Frozen decision history — workflow logs

This directory is **read-only decision history**. Files here were moved from `docs/decisions/<feature>/workflow.md` on feature completion and are no longer edited in place.

A workflow log records stage status, approvals, re-approvals, review rounds, the model that served each role, and verification evidence for a single feature. It is governance state, not behavior documentation. To understand what the system does, read the code.
